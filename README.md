# JustASite — сайт о USM

JustASite — информационный сайт о Молдавском государственном университете (USM, **Universitatea de Stat din Moldova**) в Кишинёве.

Сайт предназначен для абитуриентов, студентов и всех, кто хочет познакомиться с университетом. Он объединяет сведения об истории USM, факультетах, исследовательских институтах, кампусе и студенческой жизни, а также информацию о поступлении.

## Страницы и возможности

- **`index.html`** — главная страница: история университета, поиск и просмотр факультетов, институты, кампус, карта, новости и раздел поступления с калькулятором стоимости обучения. Основной контент доступен на румынском, русском и английском языках.
- **`faq.html`** — ответы на частые вопросы о поступлении, оплате, общежитиях, стипендиях и Erasmus+, с поиском по вопросам.
- **`tour360.html`** — панорамный просмотр кампуса с перемещением изображения мышью.

## Технологии и ресурсы

Сайт написан на HTML, CSS и JavaScript без фреймворков. Это статический проект: для запуска не нужны серверная часть, база данных или сборка.

Папка **`assets/`** является частью сайта и содержит:

- `assets/css/` — стили страниц и панорамы;
- `assets/js/` — интерактивность, переключение языка, поиск и калькулятор;
- `assets/img/` — фотографии, логотипы и другие изображения.

## Локальный запуск

В корне проекта выполните:

```bash
python3 -m http.server 8000
```

Затем откройте [http://localhost:8000](http://localhost:8000) в браузере.
